# 🎓 66Notes BUBT – Student Dashboard

**66Notes** is a lightweight, mobile‑first student dashboard built for **BUBT Intake 66 (Section 4)**.  
It helps students track live class status, exam reminders, faculty contacts, classroom codes, and the semester routine – all in one place.

🔗 **Live site:** [https://66notes.github.io/](https://66notes.github.io/)

**👤 Created & maintained by:** Ridwan Nafi *(in short – somewhere)*

---

## ✨ Features

- **AI Reminder** – live class status (running / next class) with a real‑time clock and visual indicators.
- **Pinned Events** – upcoming exams, supplementary registration, midterm syllabus previews with expandable details.
- **Class Routine** – semester schedule with room numbers and a warning for tentative changes.
- **Classroom Codes** – one‑click copy for Google Classroom join codes, including a dedicated *66notes* class code.
- **Faculty Directory** – contact info, room numbers, departments, and email addresses for each instructor.
- **Resource Links** – quick access to Google Drive and Google Classroom for study materials.
- **Fully Responsive** – optimized for both desktop and mobile devices.

---

## 🛠️ Tech Stack

- **HTML5** – semantic markup
- **CSS3** – custom styles with a modern, clean design system (no frameworks)
- **JavaScript (vanilla)** – dynamic content, live clock, AI reminder, copy‑to‑clipboard, event toggles
- **Font Awesome** – icons
- **Google Material Symbols** – additional UI icons
- **Google Fonts (Poppins)** – typography
